# PrepTalk

PrepTalk is an AI-powered presentation practice coach built for StormHacks 2026.

Users enter a presentation topic and select a target audience. PrepTalk uses the Google Gemini API to generate realistic presentation questions and provide structured feedback on written answers.

## Features

- Generate 3 audience-specific presentation questions
- Select a question and practice answering it
- Receive AI feedback on:
  - Clarity
  - Relevance
  - Strengths
  - Areas for improvement
  - Improved sample answer

## Built With

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Google Gemini API
